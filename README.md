# KAY OS Portfolio

A recruiter-friendly cybersecurity and software development portfolio with an interactive desktop experience called **KAY OS**.

## Features
- Responsive portfolio homepage with projects, experience, and contact section
- KAY OS desktop overlay with clickable app shortcuts and windows
- Keyboard accessibility (Escape closes desktop; Tab navigation)
- No frameworks, build step, or external dependencies

## Local preview
Open `index.html` in a browser, or run `python -m http.server 8000` in this directory and visit `http://localhost:8000`.

## GitHub Pages
1. Upload the contents of this folder to the **root** of your `kay-os-portfolio` repository (keep `index.html` at root).
2. Commit to the `main` branch.
3. Go to **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Choose `main` and `/(root)`; click **Save**.
5. After deployment, visit `https://cipherKay.github.io/kay-os-portfolio/`.

## Before sharing publicly
Review all project descriptions for accuracy, add verified contact/resume links, and replace summary-only demos with sanitized examples or screenshots you have permission to share. Never upload secrets, proprietary data, or internal employer code.
